생성 확인창의 비는 공유 배경에 장비 제목을 잘못 넣은 흔적이어서 제거했다. 별도 네/아니오 선택지를 수정했다. 장비/아이템/마법/보물 제목, 악마 상태창, 마법 63개, 선택지 33개를 반영했다. 필드·전투 소지금은 c01 명령 글꼴과 문자열 표를 함께 적용해 수정했다.

악마 이름 252개+종족26개+기존 아이템8개+마법63개+선택지33개=382개는 CPU 복사와 실제 비트맵이 일치한다. 화면581글자/37184픽셀과 영상46글자를 검사했다. 12개 시나리오에서 지정 글꼴 영역 밖 CHR 변경은 0바이트다. IPS 두 가지도 배포 ROM과 일치한다.

동료 악마가 없다는 사용자 답변에 따라 검사 전용 RAM에 픽시를 넣어 상태창을 확인했다. 이 내용은 사용자 세이브나 배포 ROM에 넣지 않았다. 사용자 파일과 c08은 보존했다. 오래된 세이브는 화면을 닫고 재진입하며, 기존에 저장된 이름은 자동 변환되지 않는다.

## 구현 요점

c08 NMI/매퍼 은행 기록/별도 SRAM/LRU 수정은 유지한다. c09는 비어 있던 PRG bank30(3C010..3E00F)에 라벨 및 영상 코드를 둔다. F738 중계→bank30 C000. C300 라벨, C700 영상 업로드, C900 영상 글꼴, CB00 상태창 제목, CC00 원본 제목 fallback, CD00/CD10 제목 코드, CD40 명령 글꼴 업로드, CDD0 진입 중계, CE00 명령 글꼴이다. F720은 기존 업로더 중계, F6D8은 상태 제목 중계다.

c09 할당기는 AGE 상위 비트로 오프닝 제목 글꼴을 보존하고 다음 전체 화면에서 해제한다. 7FEC 플래그 추가. 기본 c08 allocator()는 그대로이며 c09만 allocator(pin_visible=True)다. 변경 허용 CHR는 0980..0B7F(동적)와 1920..1AEF(명령 글꼴)뿐이다. 명령 글꼴은 렌더링/NMI가 꺼진 전체 화면 갱신에서 업로드한다.

선택지 포인터6BC34/count92, 문자열6BCEC..6C00F는733/804바이트. 마법 포인터55C4C/count63, 문자열55CCA..55E5B. 이름 선택표7A8FE81바이트, 기본 이름7A9C7부터8바이트씩3명. 생성 확인창6D122는열우선24바이트, 대화 네/아니요와 다르다.

## 다음 첫 작업

사용자에게 c09를 전달하고 실제 플레이에서 새 문제나 미번역 화면을 받으면 해당 경로부터 고친다. 아직 전체 대사·교섭·다른 상점 이벤트·나머지 아이템 번역은 남아 있다. 원작 제목 로고도 미작업이다. 모든 장비/동료 구성과 장시간 플레이를 검증한 것은 아니다. 확장 글꼴 동시31종 한도와 글자 공간을 다음 번역마다 확인한다. 매퍼 교체 필요성은 현재 확인되지 않았으며 부팅 속도는 그대로다.

c01 메뉴 기준판과 복구 번역140개는 보존했다. 이전 상세는 `docs/c08_재개기록_보존.md`, `docs/c08_그래픽과_상태창_수정.md`, `docs/c07_재개기록_보존.md`에 있다. 전체 번역률은 아직 신뢰할 수 있게 확정하지 않았다.

## 사용량과 작업 방식

이번 재개 시 Plus 잔여량은 5시간98%, 주간84%, 초기화권0개였다. 사용자가 직접 초기화했으며 도구로 초기화권을 쓰지 않았다. 사용자 지정은 Astra high이나 현재 모델/effort를 도구로 독립 확인하지 못했다. 새 에이전트를 추가하지 않았고, 기존 기록을 활용한 수정과 최종 해시 기준 검사만 수행했다. 영구 메모리는 갱신하지 않았다.
