# 작업 기록

AI(c01~c15 OpenAI Codex, c16 이후 Anthropic Claude)가 이 패치를 만들면서 남긴 작업 노트를 그대로 옮긴 것입니다.
빌드마다 무엇이 문제였고, 원인이 어디였고(주소·명령 바이트), 어떻게 고치고 검증했는지가 적혀 있습니다.

- [RESUME.md](RESUME.md): 빌드별 인계 기록 — **위가 최신**입니다.
- [docs/](docs/): 빌드별 상세 문서. 최신은 [c29 대사 스크립트 잘림](docs/c29_스크립트_C4FF_잘림.md).

읽을 때 참고:
- 문서에 나오는 `tools/`, `결과/`, `임시/`, `작업한 롬파일/`, `패치파일/`, `참고/` 등은 작업자 PC의 작업 폴더 경로이며
  이 저장소에는 없습니다(롬·세이브·원문 대본·다른 사람의 자료가 섞여 있어서).
- 주소: 「PRG 0x…」는 iNES 헤더(16바이트)를 뺀 위치, 「파일 0x…」는 헤더를 포함한 위치입니다.
  한글판은 롬을 512KB로 늘리면서 원판 PRG를 뒤쪽으로 옮겼으므로 **한글판 뱅크 N = 원판 뱅크 N−32**입니다.
- 작업 중에 쓴 노트라 문체가 거칠고, 나중에 틀린 것으로 밝혀진 가설도 고치지 않고 남아 있습니다. 같은 주제는 최신 문서가 우선입니다.
- 사용·수정·재배포 조건은 저장소의 [LICENSE.md](../LICENSE.md)와 같습니다.
