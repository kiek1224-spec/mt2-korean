## 이번 반영

- 시스템·메뉴·자동이동·엔딩 대사 63개 번역 또는 교정. 초기 메뉴 번역 초안도 실제 ROM에 반영했다.
- 별도 선택지 46개 번역 또는 교정: 설득/위협/안심시키기/무기 거두기, 대화 상대, 투기장, 음식, 보석, 교환 아이템 등.
- 기존 저장 소실 수정, 전투 상태·행동, 아이템219개 및 악마 이름 번역 유지.
- 일본어 원본과 Darrman 참고 자료를 대조했다. 참고 영문판의 임시 문자열 a/b/c와 일부 오역은 번역 근거로 사용하지 않았다.

`combat` 표 290개 중 274개에 번역문이 들어 있다. 나머지 16개(ID 0,1,2,27,29,32,33,38,48..52,116,117,246)는 빈 문장·변수·제어 명령이다. 이 표 기준의 정리이며 전체 게임 번역률을 뜻하지 않는다.

별도 선택지92개는 기존 c09 33개 + 이번46개 + c07 상점 가격 포함8개 + 숫자5개다. 이번 공용 이름 복사 검사는 번역문79개를 대상으로 했다. 숫자와 기존 가격8행은 원래 바이트를 보존했다.

## 검증 결과

`tools/verify_c14.py --release` 통과. 증거 `결과/codex/c14_verification.json`.

- 수정한 시스템63개는 일본어 원본의 줄바꿈·변수·대기·페이지·특수명령 순서를 모두 보존했다. 체크맨 선택 FA3C도 그대로다.
- 진단 ROM의 실제 대사 엔진으로73개 분할 화면을 캡처해 한글·공백 비트맵을 검사했다. 긴 COMP 메뉴는 이 검사에서 나누었으며 실제 메뉴 화면에서도 별도 확인했다.
- 엔딩5개는 원래 NEXT/JUMP/대기 명령을 유지한 연속12페이지,399글자 검사를 통과했다. 진단용 상점 창을 이용했으므로 최종 보스부터 엔딩 장면 전체를 진행한 검증은 아니다.
- 선택지79개는 실제 CPU 이름 복사와 글꼴 업로드를 모두 검사했다. 큐 가득참0, 비트맵 오류0.
- 실제 COMP 메뉴·메시지 속도 변경·전투부터 승리까지 조작했다. 메뉴/전투70글자의 화면 픽셀 일치와 허용 글꼴 범위 외 CHR 변경0을 확인했다.
- 두 저장 슬롯을 각각 새 Mesen 프로세스에서 불러와 이름/파티와 저장4096바이트 유지, 표식FF, 원작 코드의 캐시 영역 오접근0을 확인했다.
- 원본용/c13용 IPS 모두 재적용하면 배포 ROM과 일치한다.

새 ROM의 실행 코드는 c13과 바이트 단위로 동일하다. 변경 범위는 전투표54010..55C4B, 선택지표6BC34..6C00F, 새 글꼴3FBA0..3FBDF뿐이다. 사용자 원본 ROM·강제 세이브·기존 배터리 파일은 덮어쓰지 않았다.

## 다음 작업

원본과 같은 문구가 남아 있는 별도 표를 `결과/codex/c14_remaining_literal_audit.json`에 기록했다:

- 텔레포트 지명8개: 신주쿠·유메노시마·마계 지역 등.
- 자동이동 지명33개: 셸터·시나가와 등. 이 표는 FF 종료 대사가 아니라10바이트 고정폭이다.
- 치료소·숫자 맞히기 등의 표21개.
- 엔딩 장면 영문 이름표49개. 위에서 번역한 엔딩 대사와 다른 표다.

이는 원문과 동일한 문자열 수이며, 각 표시 경로의 실사용 여부와 고정 좌표는 아직 확인하지 않았다. 원문과 다른 기존 번역의 품질까지 보증하는 수치도 아니다. 다음 첫 작업은 텔레포트 지명 표의 공용 이름 descriptor와 자동이동 고정폭 출력 루틴을 확인하고, 대사 엔진용 escape를 무작정 넣지 않는 것이다.

일반·교섭 script1/2/3은 상당수 기존 v37 번역이 들어 있다. 원문과 동일한 블록 검사로 나온5건은 주로 이벤트 명령의 인수라 단순 미번역으로 세지 않는다. `결과/codex/c14_unchanged_script_candidates.json`은 검토 후보일 뿐이다. 기존 번역의 자연스러움, 누락, 고유명사 일치와 각 장면의 렌더링 검수가 남아 있다. 전체 한글화 완료판이 아니다.

글꼴 page3은 DB40..DBFF의24개 중18개 사용,6개 남았다. 이번 추가 글자는 규/낱/됨/량/뺄/욱/점/칙이다. C4는 일반대사와 공용이름 reader에만 지원되며 고정폭/별도 전체화면 경로의 지원을 가정하지 않는다. 동시 동적 글꼴31종 제한은 그대로다.

옛 강제 세이브는 이미 그린 화면을 보관하므로 화면을 나갔다 다시 들어와 확인한다. 새 ROM에서 게임 안 저장을 다시 하면 이후 해당 ROM의 저장을 이용할 수 있다.
