## 대상

필드의 마을 이름표 19개(하네다·시나가와·아리아케·시바·롯폰기·시부야·긴자·우에노·고라쿠엔·신주쿠·나카노,
마계의 탄식/슬픔/광기/분노/잠의/파리 마을, 이케부쿠로, 분노의 다리)와, 1인칭 간판 중 가타카나였던 2개
(게이힌 셸터, 호텔 프린세스). 나머지 간판(POISON BAR, ARMORY, CLINIC, SHOP 등 13개)은 **원판부터 영어**라 그대로 뒀다.
지명 표기는 c15 텔레포트·자동이동 번역과 맞췄다.

## 원리

이름표는 대사 글꼴이 아니라 **오브젝트 스프라이트**다. ID 표는 `$80C0`(필드 PRG bank `3C`, 1인칭 bank `34`), 레코드는
`x, y, (w-1)<<4|(h-1)` 다음 (타일, 속성) 쌍. 글자는 CHR-RAM 뱅크 `0x62`의 타일 `$80-$BF`(64칸, 가타카나+라틴+테두리)다.
필드는 스프라이트 슬롯 2에 0x62를 늘 걸어 두고, 1인칭은 간판을 띄울 때 `C794`가 `$9000=0x62`로 바꾼다.
필요한 한글이 51종이라 한 뱅크에 정적으로 못 넣는다(여유 빈 1K 뱅크도 없다: 원판 256뱅크 전부 사용, 중복은 0x53=0xF9 하나).
그래서 **이름표가 나타날 때 그 이름표의 글자만 타일 `$80-$85`에 올린다.**

1. **감지(NMI 뒷부분, 시간 여유)**: 오브젝트 갱신 `F3DD STA $0100,Y`(ID 저장)를 `JSR $F6D1`로 바꿨다. `F3E0 LDA #0`은
   바로 `F3E2 LDA $5C`에 덮이는 죽은 코드였다. `F6D1..F6D6`(참조 없는 죽은 코드)에서 ID를 저장하고 codex 트램펄린
   `FFDB`로 간다. 그 목표 `FFE7 JSR $DA00`을 bank31 `W1 $DD40`으로 돌렸다. W1은 스택의 복귀 주소가 `$F3DF`일 때만
   이 훅으로 보고, 아니면 원래 할당기 `JMP $DA00`(X·A만 건드림, 할당기는 입력 X를 안 씀)이다.
   (`$0344`&$3F, ID) 쌍이 표에 있으면 `$601F` = 이름표 번호+1.
2. **업로드(NMI 앞부분)**: `FFAA` 14바이트를 같은 길이로 `LDA $6022 / EOR $6023 / ORA $601F / BNE FF8A / JMP FC9D`로
   바꿨다(+4사이클). bank31 `$C000`(원래 `JMP $DC00`)은 `W2 $DD75`로 가서, 원작 NMI의 화면 작업 플래그
   `$0373/$0380/$03CA/$03D7`가 모두 0이고 `$0302` bit7이 꺼진 프레임에만 bank29를 `$A000`에 붙이고(그림자 `$0345` 갱신)
   `$B400` 업로드를 부른 뒤 원래 업로더 `$DC00`으로 넘어간다. 업로드는 슬롯 0(`$8000`)을 잠깐 0x62로 바꿔 3타일을 쓰고
   codex 그림자 `$6046`로 되돌린다. 3타일씩 두 프레임.
3. `$601F`는 codex SRAM 배치(AGE `6000..601E`, NX `6020`)의 빈틈이다. 배터리에 쓰레기 값이 남아 있어도 W2가
   1..21(+bit6) 외에는 0으로 지운다.
4. 글꼴은 Galmuri7(SIL OFL 1.1, `C:\gbstudio\font\Galmuri7.bdf`) 7×7을 8×8 타일의 1..7행에, 배경색 1·글자색 3으로.
   bank29 `$B400..$B7CC`에 1bpp 51자 + 이름표별 목록. bank29 앞부분은 부팅 CHR 압축 데이터(`$1280` 부근까지)다.

## 검증 (최종 해시 기준)

- 21개 전부: 세이브 6(필드, 메뉴 닫기)·세이브 3(1인칭, 돌아섰다 돌아오기)에서 `F3DD`의 ID만 대상 ID로 바꿔 실제 경로로
  그리게 하고, 같은 입력의 c15와 비교. 뱅크 0x62 타일 비트맵 일치, **다른 CHR 차이 0**, OAM이 새 타일 참조,
  업로드 마지막 쓰기 스캔라인 252(vblank 안), vblank 끝(258+/프리렌더) PPU 쓰기가 c15보다 늘지 않음.
- ID를 바꾸지 않은 실제 재그리기: 필드 「하네다」, 1인칭 「게이힌 셸터」.
- 저장 두 슬롯 콜드부팅 LOAD(`verify_c10_saves` 동일 조건, 허용 범위에 bank29만 추가): 원작 코드의 캐시 접근 0.
- 할당기 경로 회귀: 선택지 33 / 악마 252 / 아이템 8 비트맵 오류 0.
- `$601F=$9F` 쓰레기 주입: 다음 NMI에 0, CHR은 c15와 동일.

## 남은 것·주의

- 구역 경계를 걸어서 넘는 자연 경로는 직접 못 해봤다(세이브 6의 하네다는 막힌 구역). ID 저장 경로는 같다.
- 옛 세이브스테이트는 OAM에 일본어 이름표가 남아 있다가 다시 그려질 때(메뉴 닫기, 돌아서기, 구역 이동) 한글이 된다.
- 7px 글꼴이라 받침 ㄹ(을·슬·롯)이 3줄로 압축돼 작게 보인다. 필요하면 글자를 손으로 다듬을 것.
- 3글자 이름은 원판처럼 반 칸 왼쪽. 반 칸 오프셋은 별도 테두리 오브젝트(ID F9)와 4px 틈이 생겨서 뺐다.
- 영어 간판 13개를 한글로 바꾸려면 `translations/popups_c16_ko.json`의 signs에 넣으면 된다(이름표당 서로 다른 글자 6개 이하).
