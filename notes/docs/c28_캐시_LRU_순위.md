## 증상

세이브 `mt2_c26_casino_5`에서 나나나에게 팔콘 아이 장착 직후 장비 화면: 「콘서버→콘서**할** 메일」, 「브레인→**햇**레인 가드」, 「보석→보**곤**」.
사용자 짐작은 「다시 들어오면 원래대로」였는데, 실측하면 장비 이름은 돌아오지만 틀린 글자가 라벨로 **옮겨 간다**(공격→곤엇, 민첩→할첩).
c26·c27 동일, c08 이후 계속 있던 문제.

## 원인 (측정)

- 재진입한 장비 화면이 요청하는 서로 다른 글자 = **30개**(31칸 안). 한도 문제가 아니다.
- 할당기 터치 루프(bank31 `$DAF4`): 요청(적중 포함)마다 다른 모든 칸의 나이를 +1, **31에서 멈춤**. 한 화면이 요청 ~50번이라
  먼저 그린 라벨·장비 이름이 금세 31에 닿아 진짜 묵은 칸과 동점.
- 교체 칸 고르기(`$DA8A`, c09 고정 비트 판): 최대 나이 중 **번호가 가장 큰 칸**(`BCC`만 건너뜀).
- 끝 시점 실측: 나이 `$1F` 12칸 중 6칸은 화면에 없음(0~4, 11), **5칸은 화면에 보임**(A1·A2·A7·A9·AA) → 빈 칸이 있는데도 AA(18번)부터 밀려남.
  밀려난 자리에 들어온 것: 할(장비할까요)·했(장비했습니다)·곤(삼절곤)·엇(무엇을).

## 수정: 정확한 LRU 순위

```
DAF4  TYA / PHA
      LDX $6020 / LDA $6000,X / AND #$7F / STA $6021   ; 건드린 칸의 원래 순위
      LDY #0
age:  LDA $6000,Y / CMP $6021 / BCS next             ; 고정(>= $80)이거나 더 늙은 칸은 그대로
      CLC / ADC #1 / STA $6000,Y
next: INY / CPY #31 / BNE age
      LDA $6000,X / AND #$80 / STA $6000,X            ; 건드린 칸 = 0 (고정 비트 유지)
      PLA / TAY / TXA / CLC / ADC #$98 / RTS
```

- 쓰던 칸들은 순위 0..30이 겹치지 않게 유지되고 가장 늙은 칸이 정확히 가장 오래 안 쓴 칸. `$1F`는 「초기화 뒤 한 번도 안 씀」 뜻으로만 남는다.
- 한 화면의 서로 다른 글자가 31개 이하면 그 화면 글자는 밀려나지 않는다(초과하는 화면은 여전히 밀림 — 칸 수 자체는 그대로).
- `$6021`은 교체 탐색의 임시값(UP). 다른 쓰기는 대사 제어코드 초기화 `$F7A8`(0으로 지움)뿐이고 값을 들고 있지 않는다.
  bank31 `$C070 JSR $F7B9`는 c07 시절 죽은 업로더.
- 고정/해제 도우미(bank30 `$C008` 전부 해제, `$C11D`·`$C530`·`$CBBD`·`$D078`·`$DD6D` 고정)와 호환: 고정 칸은 순위가 멈춰 있다가
  해제되면 다른 칸과 순위가 겹칠 수 있지만, 그때도 지금보다 나쁘지 않다(동점 → 번호순).
