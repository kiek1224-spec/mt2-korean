## c08에서 바뀐 점

원인은 NMI 지연에 따른 원작 PPU 쓰기 초과, 누락된 CHR 은행 기록, 원작 스택과 한글 큐 중복, 순환 글꼴 덮어쓰기와 큐 포화 시 공백 반환이었다. NMI 한 번당 한 글자 전송, 두 STX 매퍼 경로 후크, 별도 SRAM 작업 공간, 최근 사용 정보에 따른 31칸 캐시로 수정했다. 금은 B7에 고정한다. 매퍼와 부팅 압축 해제는 유지한다.

새 SRAM: 최근 사용 정보 `7F60..7F7E`, 큐와 캐시/상태창 임시 변수 `7F80..7FEB`. 새 코드: bank31 `DA00` 할당기, `DC00` 업로더, `DE00` 사람 상태창 라벨. `F6B8` 상태창 호출 중계, `F6D8` 장비 제목, `FFD2` STX 은행 후크, `FFDB` 할당기 호출 중계. 프로그램 은행 기록 `0343`도 갱신한다.

사람 상태창의 소지금·보석·상태·장비·체력·지력·공격·민첩·운을 번역했다. 여덟 줄의 장비 없음 문구가 끝까지 표시된다. 이름 286개는 CPU 결과와 업로드된 실제 글꼴을 모두 대조한다. 상태창/전투/상점/기존 손상 세이브의 장면 이동에서 지정 글꼴 영역 밖 CHR 변경은 0바이트였다. 세부 결과와 최종 ROM 해시는 검증 JSON이 기준이다.

## 다음 첫 작업

**c08을 기준으로 필드·전투의 별도 소지금 제목과 악마 상태창을 분석한다.** 사람 상태창만 이번에 번역했고 악마 상태창 레이아웃은 아직이다. 상태창 원작 데이터는 CHR 압축 타일맵이며 일반 대사 문자열과 다른 경로다. Darrman `참고/upstream_Darrman/Cartographer/trimmed/status screen.txt`를 참고한다.

일반 확장 글꼴 슬롯은 여전히 31개다. 최근 사용 글자 보존으로 반복 문구와 이름 문제를 해결했지만, 동시에 보이는 서로 다른 글자가 31개를 넘는 모든 화면까지 보장하지 않는다. 여러 장비를 착용한 상태, 악마 상태창, 긴 대사를 새로 시험해야 한다. 매퍼 교체 필요성은 현재 확인되지 않았다.

사용자 세이브 `_1`로 사람 상태창을 열고, `_6`으로 전투, `_4`로 기존 손상 상태에서 진료소까지 진행했다. 모두 `../Mesen_2.2.1_Windows/SaveStates/mt2_codex_c07_shop_*.mss`. c08 최종 검사 입력과 화면은 `결과/codex/verification/c08_final_*/run.json`과 같은 폴더에 있다. 원본 파일은 보존한다. 강제 세이브의 옛 화면은 닫고 다시 열어야 한다. 추가 세이브 요청은 현재 하지 않았다.

## 이전 번역과 제약

c07은 첫 상점 아이템 8개, 소지금, 네/아니요와 구매/판매 문구를 수정했다. 아이템 영역 1467/1467바이트, 선택지 679/804바이트, 빈 글꼴 라이브러리는 5칸이다. c06의 악마 고정 이름 249개 한글+3개 알파벳, 종족 26개를 유지한다. c01 메뉴 기준판과 복구 번역 140개도 보존했다. 전체 번역률은 신뢰할 수 있게 확정하지 않았다.

이전 상세 이력은 `docs/c07_재개기록_보존.md`, `docs/번역_잔여량_2026-09-24.md`, `docs/Darrman_최종점검_2026-09-25.md`를 참고한다. 과거 “업로더 표시 구간 쓰기 0건”은 원작의 뒤이은 쓰기까지 검사한 것이 아니므로 그래픽 무결성의 충분한 근거로 사용하지 않는다.
