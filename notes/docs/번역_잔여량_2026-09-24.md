# 한글화 잔여량 조사 (2026-09-24)

## 현재 판단

c03의 **전체 번역률을 신뢰할 수 있는 단일 백분율로 표시할 단계는 아니다.** v37에서 이어받은 한국어 데이터가 예상보다 많지만, 그 데이터의 원문 대응·문맥·화면 폭·분기·후반부 플레이 검수가 끝나지 않았다. 새 c03 빌드에서 독립적으로 삽입하고 화면을 확인한 문구는 COMP 메시지 ID 3 하나다.

4개 핵심 메시지 포인터 영역의 규모는 **1,450개 항목**이다. 이 중 c03에서 한글 동적 글꼴 코드 `B8`/`B9`가 들어 있는 항목은 **986개**다. 일본어 원본의 같은 항목에는 해당 코드가 없다. 235개는 바이트 내용이 원본과 같고, 229개는 내용이 바뀌었지만 해당 글꼴 코드는 없다. 따라서 적어도 한국어 삽입 흔적은 광범위하다. 이 수치는 번역 완료 항목 수나 남은 항목 수가 아니다. 이벤트 인수·표시용 제어 데이터·포인터 중복·일부만 번역된 문장이 섞일 수 있다.

| 영역 | 포인터 항목 | 한글 글꼴 코드 포함 | 원본과 바이트 동일 | 변경됐으나 해당 코드 없음 |
|---|---:|---:|---:|---:|
| 본문 1 | 464 | 300 | 94 | 70 |
| 전투·시스템 | 290 | 268 | 12 | 10 |
| 본문 2 | 492 | 297 | 98 | 97 |
| 본문 3 | 204 | 121 | 31 | 52 |
| 합계 | **1,450** | **986** | **235** | **229** |

포인터 수는 실제로 같은 문구를 가리키는 중복을 포함한다. c03의 4개 영역에서는 986개 포인터가 서로 다른 **984개 주소**를 가리킨다. 각 문구는 현재 포인터에서 다음으로 높은 서로 다른 포인터까지를 범위로 삼아 비교했다. 내용 변경 1,215개를 모두 한국어 번역으로 간주하지 않는다.

`c03`과 이전 `v37`의 같은 1,450개 항목을 대조하면 이번 c03에서 내용이 새로 바뀐 것은 **전투·시스템 ID 3 하나**다. 따라서 c03에서 발견되는 많은 한국어 흔적은 v37의 기존 작업을 계승한 것이며, 이번에 새로 번역·검수한 결과로 기록하면 안 된다.

별도의 `translations/combat_ko.json`에는 32개 한국어 초안이 있다. 일본어 원문과 제어코드 순서는 검사했으며 c03 빌드에는 ID 3만 명시적으로 삽입했다. 이후 c04의 실제 바이트와 대조하니 ID 3을 포함해 **4개는 이미 초안과 동일**했다. **23개는 현재 칸보다 길고, 1개는 `뺄` 글꼴 코드가 없다.** 현재 칸에 들어가면서 문안이 다른 것은 ID 5·18·31·39 네 개다. c03의 나머지가 모두 일본어라는 뜻은 아니다. v37에서 이미 한국어로 바뀐 경우가 많다. 자세한 항목별 근거는 `결과/codex/combat_draft_fit.json`이다. `translations/legacy_v09_text.json`의 복구 이름 140개도 보존되어 있지만, 현재 v37의 이름과 중복할 수 있으므로 986이나 32에 더하지 않는다.

이 4개 영역 밖에도 아이템·악마·마법·종족 이름, 지명, 선택지, 제목, 고정 타일 메뉴, CHR에 저장된 화면용 텍스트가 있다. Darrman의 추출 정의에는 아이템 이름 219개, 악마 이름 253개, 마법 이름 63개, 종족 이름 27개의 포인터 칸이 별도로 보인다. 이는 총량을 파악하는 보조 자료이며 현재 한국어 품질을 뜻하지 않는다. 현재 c03에서는 COMP 본문은 확인됐지만 바깥 필드 메뉴 제목 등은 아직 화면 정리가 필요하다.

## 보관된 언어판과 패치의 쓰임

| 자료 | 이번에 확인한 것 | 활용 범위 |
|---|---|---|
| 중국어 롬 | 기존 조사에서 CHR 페이지 9개와 텍스트 일부 변경, 추가 CHR 128 KiB는 모두 0 | 짧은 메뉴·고정 글꼴·타일 배치 참고 |
| 스페인어 V2 IPS·롬 | 현재 일본판에 IPS를 적용하면 보관 롬과 바이트가 같음. 다만 제작자 설명의 요구 원본 CRC `96773F32`와 현재 일본판 `7F8D4BC6`이 다름 | 텍스트 재배치·용어·화면 구성의 정적 참고. 보관 롬을 제작자가 검증한 실행판으로 취급하지 않음 |

스페인어 IPS가 보관 롬을 정확히 재현한다는 사실은 **그 보관 롬의 출처**를 설명한다. 패치 제작자의 요구 원본과 일치한다는 뜻은 아니다. 일본어 원문을 최종 기준으로 두고, 번역판들은 개별 표현과 기술 구현을 비교하는 데 사용한다.

## 남은 일의 우선순위

1. 이미 눈으로 확인된 필드·COMP 화면의 메뉴 제목, 이름, 커서, 줄 넘침을 정리한다.
2. 4개 핵심 영역의 문구를 이벤트 인수와 표시 문자를 구별해 추출하고, ID별로 `일본어 유지 / 한국어 부분 변경 / 번역됨 / 실행 검증됨`을 분리 기록한다. 이 단계가 끝나야 믿을 만한 잔여 번역률이 나온다.
3. 기존 문구와 다른 초안을 화면별로 삽입한다. 23개는 칸 확장 또는 문안 조정이 필요하고, `뺄` 글꼴도 확보해야 한다. 실제 화면·선택 동작을 확인한다.
4. 이름·지명·기타 메뉴, 본편 후반부, 전투와 악마 대화의 화면 검수를 이어 간다. 원본의 이벤트 명령과 줄바꿈·변수를 보존한다.

기계적으로 다시 확인하려면 `python tools/audit_translation_scope.py`를 실행한다. 숫자와 ROM 해시는 `결과/codex/translation_scope.json`에 저장된다. 이 조사는 롬이나 세이브를 수정하지 않는다.
