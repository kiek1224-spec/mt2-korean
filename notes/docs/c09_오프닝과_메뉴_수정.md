## 변경 사항

오프닝 영상의 두 자막을 “199X년 인류의 역사는 끝났다.”와 “그리고 시간은 흘러...”로 바꿨다. 데빌 버스터 안내 제목과 두 페이지 본문, 소년·소녀·친구의 이름 입력 안내를 자연스럽게 고쳤다. 원작 타이틀 로고 이미지는 그대로다.

이름 입력판은 사용자 선택대로 한글 음절 50개와 영문 A–Z, 문장부호를 사용한다. 자모 조합식은 아니다. 다음·이전은 이름의 입력 위치 이동이며 완료는 입력을 끝낸다. `가다A`를 실제로 입력하여 RAM 저장 값을 확인했다. 빈 이름의 기본값은 나 / 여자 / 동료다. 기존 세이브에 이미 저장된 이름은 자동 변환하지 않는다.

능력치 배분 확인창의 ‘비’는 미번역 문자가 아니라, 사람 상태창과 캐릭터 생성이 공유하는 배경에 ‘장비’ 제목을 덧그린 오류였다. 공유 배경의 장비 덧그리기를 없애고 장비창 전용 제목 경로를 유지했다. 확인창의 별도 예/아니오 데이터는 네 / 아니오로 고쳤다. 일반 대화의 기존 네/아니요와는 별도의 경로다.

악마 상태창의 교대 포인트·상태·마법과 능력치 항목을 한글로 표시한다. 장비 / 아이템 / 마법 / 보물 제목도 확장 글꼴을 읽는 경로로 통일했다. 마법 이름 63개와 선택지 33개를 반영했다. 선택지에는 구매·판매·상태 보기·나가기, 술집 음료와 상대 선택, 데빌 버스터, 저장, 합체, 치료 등이 포함된다. 이름은 일본어 원문을 대조한 프로젝트 표기이며 공식 한국어판 용어라고 주장하지 않는다.

필드·전투의 ‘소지금’은 대사 글꼴이 아닌 명령 전용 글꼴을 쓴다. c08에 남아 있던 v37 글꼴 표와 c01 문자열의 코드가 달라 글자가 바뀌어 보였다. 검증된 c01의 명령 문자열과 글꼴을 한 쌍으로 적용했다. 명령·필드·전투·주인공·동료·악마 명령, 게임 오버의 예/아니오, 총/검 선택도 같은 표를 사용한다.

## 구현과 안전 범위

원본과 Darrman의 로컬 참고 자료를 사용했다. `참고/upstream_Darrman/Cartographer/trimmed/status screen.txt`, `in dialogue choices.txt`, `spells.txt`, `combat.txt`, `Atlas/script/menu commands.txt` 등이 근거다. 참조 저장소는 https://github.com/Darrman/MT2_Translation 이다.

PRG bank 30의 `3C010..3E00F`가 c08에서 전부 FF인 것을 빌드 시 확인하고 화면 라벨과 자막 코드/데이터를 넣는다. 매퍼와 ROM 크기, 부팅 압축 해제 방식은 유지한다. 제목 표시와 영상 자막은 일반 대사와 다른 글꼴 경로이므로 따로 처리했다.

오프닝 안내의 제목이 다음 본문에서 덮어써지지 않도록 캐시 최근 사용 정보의 상위 비트로 화면에 남는 제목 글꼴을 보호한다. 다음 전체 화면을 그릴 때 해제한다. 제목 포함 둘째 안내 화면의 서로 다른 확장 글자는 30개로 31칸 안에 들어간다. SRAM `7FEC`를 보호 상태 플래그로 추가했다. 일반 확장 글꼴의 총량을 늘린 것은 아니다.

명령 글꼴은 전체 화면 갱신 시 렌더링과 NMI가 꺼진 구간에서 기존 CHR page 6의 지정 칸에 넣는다. 변경 허용 영역은 동적 글꼴 `0980..0B7F`와 명령 글꼴 `1920..1AEF`다. 임의의 스프라이트나 배경 타일을 빈 공간으로 간주해 쓰지 않았다.

## 검증

Mesen의 격리된 실행에서 실제 입력과 화면을 기록했다. 사용자 세이브·설정은 덮어쓰지 않았다. 검사 전용 ROM의 이벤트 변경은 배포 ROM에 들어가지 않는다.

- 악마 252개 + 종족 26개 + 아이템 8개 + 마법 63개 + 선택지 33개 = 382개: CPU 이름 복사 결과와 실제 업로드된 글꼴이 일치한다.
- 화면 글자 581칸, 표시 픽셀 37,184개 및 영상 자막 46칸 비트맵을 검사했다. 커서가 가리는 칸은 커서를 옮긴 화면에서 검사한다.
- 오프닝 두 안내 페이지, 이름 3명 입력, 능력치 확인창, 사람·악마 상태창, 필드, 새 전투, 상점, 제공된 메뉴 3곳 등 12개 시나리오에서 지정 글꼴 영역 밖 CHR 변경은 0바이트다.
- 실제 이름 `가다A` 저장, 빈 이름 대체, 다음/이전 위치 이동, 확인창의 제목 잔재 제거를 확인했다.
- 원본→c09, c08→c09 IPS를 다시 적용해 두 결과 모두 배포 ROM과 일치함을 확인했다.

사용자에게 아직 동료 악마가 없으므로 악마 상태창은 검사 전용 RAM에 픽시를 넣어 확인했다. 실제 플레이로 영입한 동료 악마나 모든 악마·마법 조합을 검증했다는 뜻은 아니다. 새 전투는 검사 전용 상점 이벤트로 픽시 전투를 시작하고 이후 배포 ROM으로 진행했다.

## 실행과 다음 작업

기존 강제 세이브는 이전 화면과 글꼴을 저장한다. 불러온 직후의 옛 화면으로 판정하지 말고, 화면을 닫고 장면을 이동하거나 다시 들어가 새로 그린 결과를 확인한다. 오프닝·이름 입력은 새 게임에서 확인한다.

빌드: `python tools/build_c09_ui.py`. 화면 검사: `tools/probe_c09.py`. 이름 검사: `tools/probe_c06_names.py --renderer c08 --tag c09`에 그룹과 ROM 경로를 지정한다. 최종 기록을 갖춘 후 `python tools/verify_c09.py --release`로 배포 파일을 쓴다. c08 빌드의 기본 할당기는 변경되지 않으며 c09만 `pin_visible=True`를 사용한다.

남은 일은 전체 대사와 교섭·상점별 이벤트, 나머지 아이템, 여러 동료/장비를 동시에 표시하는 조합이다. 제목 로고 이미지도 아직 원작이다. 긴 문구의 공간과 동시 확장 글자 31칸 한도는 다음 번역마다 확인해야 한다. 부팅 속도 개선과 매퍼 교체는 이번에 하지 않았다. 이번 검증으로 매퍼 교체 필요성은 확인되지 않았다.
